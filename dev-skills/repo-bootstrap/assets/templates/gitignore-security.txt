# -----------------------------------------------------------------------------
# Secretos y credenciales: nunca versionar.
#
# Este archivo NO es un .gitignore completo. Es un FRAGMENTO que el instalador
# de repo-bootstrap fusiona con el .gitignore que el proyecto ya tenga, sin
# pisarlo.
#
# Por que importa: lo que entra a un commit queda en el historial del repo para
# siempre. Borrar el archivo despues no lo saca de los commits anteriores, y en
# un repo publico ya lo vio cualquiera. La unica salida real es rotar la
# credencial.
# -----------------------------------------------------------------------------
