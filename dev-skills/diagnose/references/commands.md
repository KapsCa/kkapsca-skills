# Comandos — Diagnose

## Tests rápidos (según stack)

```bash
# Correr tests rápidos (según stack)
flutter test
go test ./...
npm test
pytest
```

## Observabilidad por stack

Usa las herramientas de observabilidad del stack:

| Stack | Herramienta |
| --- | --- |
| Dart | `print` |
| Go | `log` |
| JS | `console.log` |
| Otros | la herramienta de observabilidad equivalente del lenguaje |
